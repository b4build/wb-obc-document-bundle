█ TROUBLESHOOTING

  Q: "Folder not found" error
  A: Double-check PARENT_FOLDER_ID (no spaces, exact copy)

  Q: "Permission denied" when authorizing
  A: Clear browser cache, try in incognito mode

  Q: Links not updated in HTML
  A: Check drive_links_mapping.json is in same folder
     Verify folder names match (case-sensitive)

  Q: Some links work, some don't
  A: Check file IDs in mapping are correct
     Re-run generate_gdrive_links.py with correct IDs

  Q: How to break links later?
  A: Delete the file in Google Drive
     Or remove "Anyone can access" permission

█ SECURITY TIPS

  • Links are "view-only" (no editing)
  • Anyone with link can access (no login needed)
  • Google Drive tracks view count
  • Delete in Drive to revoke access
  • Use different folders for different teams if needed
